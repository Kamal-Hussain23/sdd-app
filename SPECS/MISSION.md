# Mission

## Why this project exists

This project helps students learn web development hands-on. We learn by
building a working cafe ordering system together.

## Who it is for

The students building it. It is a learning project, not a product for a real
business.

## What it does

- Customers scan a QR code at their table to open the menu and place an order.
- Staff can see the incoming orders and track how each one is being processed.

## What success looks like

A simple but complete app that works end-to-end, and that the students
understand, can extend, and are proud of.

## Values (non-negotiable)

- **Keep it simple.** Code should be easy to read and understand.
- **Easy to extend.** Adding a new feature later should be straightforward.

## Out of scope (for now)

- Payments — we do not handle money.
- Logins or accounts — nobody needs to sign in.
- Anything that needs a database or saving data to disk.
